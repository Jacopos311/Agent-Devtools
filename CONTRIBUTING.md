# Contributing to Agent DevTools

Thank you for your interest in contributing to **Agent DevTools**! We welcome contributions from developers of all skill levels. Whether you are fixing a bug, improving documentation, or adding a new feature, your help is greatly appreciated.

---

##  How to Get Started

### 1. Report Bugs
If you find a bug, please check the [existing Issues](https://github.com/tuo-username/agent-devtools/issues) first to see if it has already been reported. If not, open a new Issue with:
* A clear and descriptive title.
* Steps to reproduce the problem.
* Expected vs. actual behavior.
* Details about your environment (OS, Python version, Browser, etc.).

### 2. Suggest Features
We love new ideas! To suggest a feature:
* Open an Issue using the feature request template (or start a Discussion).
* Explain **why** this feature would be useful for debugging AI agents.
* Describe how you envision it working.
